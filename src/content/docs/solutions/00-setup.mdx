## Common pitfalls and fixes

| Pitfall | Symptom | Fix |
|---|---|---|
| OIDC subject mismatch | `deploy.yml` what-if fails with `AADSTS700213` / "No matching federated identity record" | Federated credential subject must be exactly `repo:<org>/<repo>:environment:lab`, and the `lab` environment must exist |
| Wrong subscription selected | Resources deploy to wrong subscription | `az account set --subscription <ID>` before any CLI commands |
| Port 4321 not forwarded | Docs site unreachable | VS Code Ports tab → right-click 4321 → Make Public (if needed) |
| Agent not responding | `@network-architect` shows no reply | Check `.github/agents/` folder exists; reload Copilot extension |
| Budget CLI fails | `"budget not supported"` | Some subscription types don't support `az consumption budget` — use Portal instead |

## Reference OIDC federated credential

```json
{
  "name": "github-actions-lab",
  "issuer": "https://token.actions.githubusercontent.com",
  "subject": "repo:NikoMix/microhack-networking-services:environment:lab",
  "audiences": ["api://AzureADTokenExchange"]
}
```

This is environment-scoped (`repo:[org]/[repo]:environment:[env-name]`) because the
`deploy.yml` and `teardown.yml` jobs declare `environment: lab`. A branch-scoped
subject (`ref:refs/heads/main`) would **not** match and the deploy login would fail.
The `oidc-bootstrap.sh --environment lab` helper sets this subject automatically.

## Trainer note — model configuration

If pupils are using **Azure OpenAI** instead of GitHub Models, they need to set
`AZURE_OPENAI_ENDPOINT` and `AZURE_OPENAI_API_KEY` as Codespace secrets, and update
`.github/models/` to point at the correct deployment. GitHub Models is the zero-setup
default and requires no Azure AI dependency.
