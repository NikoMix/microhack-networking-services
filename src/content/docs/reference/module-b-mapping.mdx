This page maps every **Module B** control of the *Networking Services in Microsoft Azure
Advanced Specialization* to the microhack challenge that satisfies it, the evidence
artifact produced, the Azure services involved, and the auditor's key checks.

<Aside type="tip" title="One engagement, multiple controls">
The CFS engagement deliberately spans multiple controls — exactly as the audit guidance
permits. A single hub & spoke deployment simultaneously satisfies B.3.1 (scenario
implementation) and B.3.2 (≥5 native services). The design artifacts satisfy both
B.2.1 and B.2.2.
</Aside>

## Module B scenario coverage

The audit recognises five scenarios. CFS covers three:

| Scenario | Covered | Challenges | Evidence |
|---|---|---|---|
| 1 — Secure network infrastructure | ✅ | 03, 04 | B3.1 + B3.2 |
| 2 — On-prem and branch connectivity | ✅ | 03 | B3.1 (VPN Gateway) |
| 3 — Remote work at scale | ❌ | Not in scope | — |
| 4 — Secure global app delivery | ✅ | 04 | B3.2 (Front Door + App Gateway) |
| 5 — 5G and edge computing | ❌ | Not in scope | — |

<Aside type="note" title="Minimum scenario requirement">
Module B requires at least **one** of the five scenarios to be implemented. CFS covers
three, which demonstrates broader capability and is typical of a partner engagement that
wants to show coverage depth.
</Aside>

## Eight B.1.1 topic areas

All eight must appear in `B1.1_RequirementsAssessment_CFS_v1.xlsx`:

| # | Topic area | CFS section |
|---|---|---|
| 1 | Business requirements | PSD2/GDPR, SLAs, budget |
| 2 | Current state | On-prem topology, MPLS branches, ageing firewalls |
| 3 | Target architecture | Hub & spoke, ALZ, Sweden Central |
| 4 | Networking services | Azure Firewall, Bastion, Private Link, App Gateway, Front Door |
| 5 | Security and compliance | PSD2 isolation, GDPR data residency, zero public PaaS |
| 6 | Hybrid connectivity | 3 branches (VPN), 1 DC (ExpressRoute design-only) |
| 7 | Identity and access | Entra ID P2, PIM, Bastion admin model |
| 8 | Operational requirements | Network Watcher, NSG flow logs, 4h RTO / 15m RPO |
