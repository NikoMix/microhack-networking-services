## What you build

A Microsoft best-practice **hub & spoke secure network** for a fictional regulated
fintech — **Contoso Financial Services (CFS)** — with **private networking, isolated
resources, and private compute**, deployed to **your own Azure subscription** via
**GitHub Actions (OIDC)** from an **Azure Landing Zone Accelerator** baseline. Along the
way you generate every artifact an auditor checks for Module B.
