Work the challenges **in order** — each builds on the previous and the same CFS
engagement carries through all seven, mirroring how one real project satisfies multiple
audit controls.

| # | Challenge | Module B control(s) |
|---|---|---|
| 00 | [Setup, Tooling & the CFS Brief](./00-setup/) | _foundation_ |
| 01 | [Requirements Assessment](./01-requirements-assessment/) | B.1.1 |
| 02 | [Solution Design + Well-Architected Review](./02-solution-design/) | B.2.1 + B.2.2 |
| 03 | [Deploy the Secure Hub & Spoke](./03-deploy-hub-spoke/) | B.3.1 + B.3.2 |
| 04 | [Private Networking, Isolation & Private Compute](./04-private-networking-compute/) | B.3.2 |
| 05 | [Validation & Testing](./05-validation-testing/) | B.4.1 |
| 06 | [As-Built, Operations & Teardown](./06-as-built-teardown/) | B.4.2 |

Each challenge page includes: **objectives**, the **agent(s)** to use, **step-by-step
tasks**, the **evidence** produced, **success criteria**, and **cost/teardown notes**.
Trainer answer keys live under [Solutions](../../solutions/).
